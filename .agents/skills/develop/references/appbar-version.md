# Appbar version details

## Ownership and behavior

- `ManifoldWeb.Layouts.appbar_version/1` renders the version beside the Manifold
  brand using `dm_appbar`'s `after_title` slot in both app and settings layouts.
- Versions use `v<version>`; only builds compiled with `MIX_ENV=dev` append `-dev`.
- A soft primary pill `dm_badge` displays the version inside a keyboard-focusable
  button that invokes the DuskMoon tooltip on hover or focus.
  Details include version, environment, Git ref, full commit SHA, release time,
  and build time. Missing values show `Not recorded`; commit time is never used
  as release time. Timestamps are ISO 8601 UTC when generated by our builds.
- Styling in `assets/css/app.css` inherits appbar theme tokens. Details wrap
  within narrow viewports; application navigation retains horizontal scrolling.
- The tooltip uses the same soft primary background and foreground tokens as the
  badge: `primary-container` and `on-primary-container` in both themes.

## Build metadata

- `ManifoldWeb.BuildInfo.current/0` returns a compile-time snapshot. Rendering
  requires neither Git nor Mix in a packaged release.
- `BuildInfo.Source` reads the web Mix project version/environment and optional
  `MANIFOLD_GIT_REF`, `MANIFOLD_GIT_SHA`, `MANIFOLD_BUILD_TIME`, and
  `MANIFOLD_RELEASE_TIME` build environment variables. Blank values are absent.
- Local builds fall back to the checkout ref/SHA and compilation time. Missing
  Git is supported. `__mix_recompile__?/0` refreshes cached metadata when source,
  version, environment, or explicit build metadata changes.
- Docker's builder accepts these four values as build arguments. The Docker
  workflow passes the actual checked-out SHA, requested ref, and UTC build time.
  Release events also pass GitHub's actual `published_at`; manual and reusable
  workflow runs without that event leave release time unrecorded.
- The archive release workflow builds before committing its version bump; its
  Git SHA therefore identifies the source checkout before that commit. Actual
  publication time is unavailable when the archive is compiled.
